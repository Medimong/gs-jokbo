# 외과학 실습족보 아카이브

서울대학교 의과대학 외과학 실습(턴말) 기출 복원본을 문항 단위로 정제한 학습 사이트다.
2022년부터 2026년까지의 복원본을 모아 중복을 합치고, 정답을 표준 교과서와 진료지침으로
재검토한 뒤, 판단 기준을 별도의 정리 카드로 묶었다.

## 쓰는 법
`index.html`을 브라우저로 열면 된다. 서버가 필요 없고 휴대폰에서도 동작한다.

- **학습** 정답과 해설이 함께 보인다.
- **퀴즈** 선지를 누르면 바로 채점되고 해설이 펼쳐진다.
- **오답** 틀린 문항만 모아 다시 푼다.
- **정리** 판단 기준을 표와 단계별 프로토콜로 모았다. 문항 해설의 "판단 기준"을 누르면 해당 카드가 열린다.

## 만든 방식
- 여러 해의 복원본을 한 문항으로 합치되, 어느 한 버전을 고르지 않고 **합쳐서 원래 시험문제를 재구성**했다.
- 복원본의 정답을 그대로 쓰지 않고 **표준 교과서와 진료지침으로 재검토**했다. 원본과 달라진 경우 그 사실을 문항에 표시한다.
- 그림은 하나씩 열어보고 관련성과 중복, 정답 노출 여부를 판정했다. 정답이 적힌 그림은 퀴즈 모드에서 가려진다.
- 조건이 달라 답이 갈리는 문항들은 같은 정리 카드를 참조하도록 묶어 나란히 배치했다.

## 주의
해설은 표준 교과서와 진료지침을 근거로 재검토한 것이며 **원본 복원본의 정답과 다를 수 있다**.
복원 과정에서 생긴 오류가 남아 있을 수 있으니 시험 대비 참고 자료로만 쓰기 바란다.
